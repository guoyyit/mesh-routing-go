# mesh-routing-go

本地多跳自组网路由与拓扑修复模拟器。面向资源受限节点组成的无线网格，
在链路频繁抖动下稳定地把数据汇聚到根节点（上行），并从根节点向任意
可达节点下发指令（下行）。路由语义参考 RPL（RFC 6550）的 DODAG 模型，
控制开销采用 Trickle（RFC 6206）自适应抑制。

## 路由语义

### 上行（多点到根）

- 每个节点维护 **Rank**（到根节点的路径代价，根为 0）与一个**首选父节点**。
- 代价采用放大 256 倍的 ETX 风格度量：完美单跳为 256，`Rank = 父Rank + 链路代价`。
- **无环不变量**（任意时刻成立，含切换过程）：
  1. 沿父指针方向 Rank 严格递减；
  2. 节点绝不选择自身下行表中的后代作为父节点；
  3. `MaxRank`（65536）上限使 count-to-infinity 快速触顶终止。
- `PathToRoot` 返回一条可用路径的下一跳、总代价与跳数。
- 父节点切换带**滞后**（`parentHysteresis = 16`）：新候选须明显更优才切换，
  链路质量小幅抖动不会引起父节点震荡。
- 转发失败返回**可区分原因**，绝不静默丢弃：

  | 原因 | 含义 |
  |---|---|
  | `no-route` | 本地没有任何可用父节点 |
  | `parent-missing` | 父节点链路已断，修复尚未完成 |
  | `loop-detected` | 无环不变量被破坏，拒绝转发 |
  | `stale-state` | 节点未接入（如重启后） |
  | `unreachable` | 下行目的不可达 |

### 下行（根到任意节点）

- 子节点通过 **DAO** 通告向父节点上报子树目的地，逐跳汇聚到根，
  根的下行表即全网路由；中间节点只保存自身子树的表项。
- 下行路径与当前上行结构一致：父节点切换时向旧父发送 **no-path DAO**
  清除陈旧表项，向新父发送常规 DAO 建立新表项；事件引起的全部变化
  在事件返回前同步传播收敛（有限时间）。
- DAO 全量替换 + 精确变化检测：无变化的重复通告不再传播，保证终止性。

### 身份与状态恢复

- **DODAG 版本**（根重启时递增）：旧版本的通告被全网拒绝，不与新拓扑混用。
- **化身序列号 Seq**（节点重启时递增）：旧化身的 DIO/DAO 被邻居拒绝；
  邻居发现新化身后清除旧化身学到的全部下行表项。
- 相同 NodeID 重复加入按重启处理，结果确定。

### 控制开销自适应抑制（Trickle）

- 拓扑稳定：发送窗口指数回退（`Imin` 翻倍至 `Imax`），控制开销明显下降。
- 拓扑变化：收到不一致信息立即重置到最小窗口，更新及时传播；
  抑制窗口内的重要变化**不会**被吞掉（重置不经抑制判断）。
- 窗口内收到 `K` 条一致消息则抑制本次冗余发送。

## 配置项

`NewNetwork(root, seed, imin, imax, k)`：

| 参数 | 含义 | 建议 |
|---|---|---|
| `root` | 汇聚根节点 ID | 任意 NodeID |
| `seed` | 随机种子 | 固定值可复现 |
| `imin` | Trickle 最小窗口（时钟步） | 1 |
| `imax` | Trickle 最大窗口（时钟步） | 8~64 |
| `k` | Trickle 冗余常数 | 1（密集网络可增大） |

协议常量（`mesh/node.go`）：`parentHysteresis`（切换滞后）、
`MaxRank`（Rank 上限）、`InfiniteCost`（不可达）。

## 事件模型与确定性

```go
net := mesh.NewNetwork(1, 42, 1, 64, 1)
sim := mesh.NewSimulator(net, []mesh.Event{
    {Kind: mesh.EvNodeJoin, A: 1},
    {Kind: mesh.EvNodeJoin, A: 2},
    {Kind: mesh.EvLinkUp, A: 1, B: 2, Cost: 256},
    {Kind: mesh.EvTick, Steps: 10},
})
logs := sim.Run() // 逐事件日志
```

- 事件类型：`EvNodeJoin / EvNodeLeave / EvNodeRestart / EvLinkUp /
  EvLinkDown / EvLinkQuality / EvTick`。
- `Simulator` 逐事件施加；`NewBatchSimulator` 将一批事件视为**并发发生**
  （先全部施加再统一收敛），用于验证并发拓扑更新不破坏无环性。
- **确定性**：固定种子 + 相同事件序列 ⇒ 逐事件日志完全一致。
  所有 map 遍历均按 NodeID 排序，节点随机源由主种子派生。
